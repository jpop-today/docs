# ADR-001: 정적 배포와 콘텐츠 중심 앱

2026-10-13 · accepted · SEARCH-001, SONG-001, SEO-001, RELEASE-001.

현재 원본은 자체 Node 스크립트로 16개 정적 페이지를 생성하며 API 서버·DB 없이 동작한다. 곡 상세는 query 기반 JS 렌더라 검색·공유 본문의 일관성을 개선할 여지가 있다. 새 조직 소스에는 아직 앱이 없다.

정적 Cloudflare 배포를 유지하고 새 앱의 페이지·편집 콘텐츠는 Astro SSG와 TypeScript로 구성한다. 프레임워크 독립 데이터 계약과 ID 어댑터는 유지한다. 검색·즐겨찾기는 최소 클라이언트 코드로 구현한다. 빌드에 실시간 수집을 결합하지 않는다.

대안은 기존 생성기만 확장하거나 Next.js 서버/DB를 도입하는 것이다. 기존 생성기는 이관 baseline으로 보존하지만 콘텐츠 스키마·라우팅·정적 상세 구조를 직접 늘리는 비용이 있다. 서버/DB는 현재 요구에 필요하지 않아 도입하지 않는다.

첫 구현은 기존 URL·저장 데이터 회귀를 보존하는 최소 앱부터 한다. 페이지 수를 늘리는 것 자체가 목표는 아니다. 스펙이 없는 UI 재작성과 새 앱 검증 전 운영 도메인 연결 변경은 하지 않는다.

검증: 고정 데이터의 재현 빌드, JS 비활성 곡/가이드 본문, 검색·저장 E2E, dist 비공개 파일 제외, 동일 SHA 미리보기·복구.
