# ADR-003: 증거와 공개 범위

2026-10-13 · accepted · DATA-001, HARNESS-001, CONTENT-001, ADS-001.

원본 등록곡은 관측된 번호를 담지만 행별 source/checkedAt가 비어 있다. 가사 publishAll:true와 외부 앨범 이미지가 있고 자료별 권리 증거는 확인되지 않았다. 파일이나 출처 링크가 있다는 이유로 사실 확인·이용 허락이 완료되지 않는다.

원본을 staging에 보존하고 관측값·검증값·권리 상태를 분리한다. 출처와 확인일을 실제 조사로 확보한 데이터만 엄격 계약으로 승격한다. source URL이나 checkedAt를 일괄 생성하지 않고, 증거가 없다고 관측 번호를 원본에서 지우지 않는다. raw→v1 변환에서 누락·KY 충돌을 보고하고 게이트를 실패시킨다.

가사·이미지·인용은 자료별 권리 evidence와 허용 범위를 확인한 allowlist에만 발행한다. 전체 공개 토글을 권리 확인으로 해석하지 않는다. 기존 운영의 공개 상태를 변경할 때는 실제 현재 artifact·프로젝트·복구와 필요한 캐시 처리를 먼저 확인한다.

수집 실패 시 원본 정상 스냅샷과 공개 artifact를 보존한다. 통과한 신규 스냅샷만 동일 디렉터리 임시 파일·원자적 rename으로 승격한다. 검증 통과는 출처의 진실성·권리·AdSense 승인 판정과 별개다.

검증: 실제 파일 실패 보존 테스트, 누락 evidence/권리 자료 artifact 유출 검사, 확인된 표본 재대조, 콘텐츠 검토 이력.
