# jpop.today 제품·운영 문서

한국어 사용자를 위한 JPOP 노래방 번호 검색 서비스의 제품 스펙, 아키텍처 결정, 데이터 기준, 검증 하네스, 운영 기록을 관리합니다.

- [운영 사이트](https://jpop.today)
- [소스](https://github.com/jpop-today/jpoptoday)
- [조직 운영 규칙](https://github.com/jpop-today/.github)

목표는 신뢰할 수 있는 검색 서비스와 고유 콘텐츠를 만들고 Google AdSense 심사를 준비하는 것입니다. 승인은 Google 심사 결과로 확인합니다.
