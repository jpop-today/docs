# AdSense 준비와 증거

상태: 미완료. 실제 계정·현재 심사 상태·게시자 ID는 아직 확인하지 못했다. 이 문서는 Google 승인 보장표가 아니라 내부 출시·신청 준비 기준이다.

## 준비 기준

| 영역 | 확인할 증거 | 현재 |
| --- | --- | --- |
| 사이트 소유·계정 | 운영자 소유, 정상 접속, 계정 자격, 기존 신청 상태 | 계정 미확인 |
| 고유 콘텐츠 | 자체 편집 가이드·곡 정보·데이터 분석의 실제 가치와 출처 | 운영 콘텐츠 관찰만 완료 |
| 탐색·기능 | 모바일·데스크톱 검색/상세/저장/문의가 작동 | 브라우저 검증 대기 |
| 데이터 권리 | 초기 자료·이미지·가사별 이용 범위/출처 | 미확인 |
| 개인정보 | 실제 로드되는 광고·분석·영상·문의와 안내 일치 | 코드 검토 대기 |
| 광고 배치 | 검색·복사·저장 버튼과 명확히 분리, 빈/오류/개인 선곡표 등 광고 범위 검토 | 설정 미확인 |
| 동의 | 적용 지역의 Google 동의 관리 요건과 실제 네트워크 동작 | 미확인 |
| 기술 | 초기 HTML, 정상 canonical, sitemap/robots, 404, 기존 URL | 상세 HTML 개선 필요 |
| 계정 연결 | 실제 게시자 ID, 검증 코드/ads.txt, 심사 결과 | 미확인 |

광고 관련 값은 실제 계정에서 받은 값만 사용한다. 가짜 ca-pub ID나 ads.txt를 만들지 않는다. 자동 광고가 기존에 활성화됐는지 코드를 확인한 뒤 변경한다. EEA·영국·스위스에 광고를 제공하는 경우 Google의 최신 CMP 요건을 확인하고 실제 적용을 검증한다. 비개인화 광고만 선택하면 모든 동의 문제가 해결된다고 가정하지 않는다.

## 신청·재심사 절차

페이지 품질과 배포 검증을 완료 → 현재 AdSense 계정 상태 확인 → 실제 계정의 사이트 연결 절차 수행 → 상태와 결과 기록 → 반려 시 표시된 사유별 수정·증거를 남김 → 재검증 후 재심사.

계정 생성에 필요한 본인 정보·결제·법적 동의는 운영자가 처리한다. 사이트 수정·검증·배포는 사용자 위임 범위에서 자율 진행한다. 자동 실행으로 심사를 통과했다고 기록하거나 Google 심사 결과 없이 승인 완료로 표시하지 않는다.

## 공식 기준 (2026-10-13 확인)

- [페이지 준비](https://support.google.com/adsense/answer/7299563?hl=ko): 고유 콘텐츠와 쉬운 탐색, 만족스러운 사용 경험
- [자격 요건](https://support.google.com/adsense/answer/9724?hl=ko)
- [프로그램 정책](https://support.google.com/adsense/answer/48182?hl=ko)
- [동의 관리 요건](https://support.google.com/adsense/answer/13554116?hl=ko)
- [사이트 심사 상태](https://support.google.com/adsense/answer/12170222?hl=ko)
- [검색 스팸 정책](https://developers.google.com/search/docs/essentials/spam-policies)

필수 글 수·글자 수·트래픽 수치·승인 소요 시간을 임의의 공식 요건으로 만들지 않는다.
