# 제품 스펙 v1

상태: 초안 기준선. 작성일: 2026-10-13 (Asia/Seoul). 원본 소스 조사 후 구조·호환성 항목을 확정한다.

## 목적과 사용자

일본어 표기나 가수명을 정확히 몰라도 기억나는 한글로 곡을 찾고, 이용하는 노래방 업체의 번호를 확인해 부를 곡을 준비한다. 핵심 사용자는 한국에서 TJ·금영 노래방을 이용하는 JPOP 청취자다.

서비스의 고유 가치는 한글·원제·별칭을 연결하는 검색, 업체별 번호와 곡 버전의 정확한 구분, 출처가 드러나는 데이터, 직접 검증한 선곡 설명이다. 단순 번호 목록이나 외부 영상만으로 콘텐츠 가치를 대신하지 않는다.

## v1 범위

검색, 필터, 곡 상세, TJ 차트, 로컬 즐겨찾기·선곡표, 가이드, 데이터 소개·문의·개인정보를 제공한다. 회원가입·사용자 게시판·실시간 데이터베이스·결제는 v1에 포함하지 않는다. 사용자 계정이 없으므로 브라우저 저장 데이터 이관을 호환성 범위에 넣는다.

## 기능과 완료 기준

| ID | 기능 | 검증 가능한 완료 기준 |
| --- | --- | --- |
| S01 | 검색 | 한글·일본어·라틴 표기·가수·업체 번호로 검색한다. 정확한 번호/제목이 부분 일치보다 우선한다. 빈 입력·0건·긴 입력·유니코드 정규화·동명이곡을 처리한다. |
| S02 | 필터 | 업체·가수·애니메이션 등의 실제 확인된 태그를 조합한다. 필터 상태가 공유 URL에서 재현된다. 초기화·0건 상태가 작동한다. |
| S03 | 곡 상세 | 원제·한글 표시·가수·곡 버전·업체별 번호·번호별 출처와 확인일이 초기 HTML에 있다. 없는 번호를 0이나 미수록으로 추정하지 않는다. 잘못된 ID는 404 또는 안내를 제공한다. |
| S04 | URL 호환 | 기존 /song?id=... 주소를 전수 목록화한다. 새 /songs/[id]/ 상세로 연결하는 호환 페이지 또는 개별 영구 리디렉션을 제공한다. 원본 ID 변경에는 별도 매핑이 필요하다. |
| S05 | 차트 | 업체·집계 기간·수집 시각·원본 링크를 표시한다. 최신 수집 실패 시 마지막 정상 스냅샷과 지연 안내를 유지한다. 금영 번호가 TJ 순위에 함께 표시돼도 금영 차트로 설명하지 않는다. |
| S06 | 즐겨찾기 | 저장·해제·재방문·전체 삭제·번호 복사·빈 상태를 검증한다. 저장 불가/손상된 localStorage에서도 앱이 작동한다. 기존 저장 키와 ID를 읽는 이관 절차가 있다. |
| S07 | 편집 콘텐츠 | 가이드마다 작성·검토 정보, 실제 예시, 출처, 구체적인 판단 근거가 있다. 미확인 음역·난이도·추천 근거를 생성하지 않는다. |
| S08 | 신뢰 안내 | 사이트·데이터 소개, 실제 문의 경로, 개인정보 처리방침, 정정 절차를 모든 주요 페이지에서 찾을 수 있다. 실제 활성화된 외부 서비스와 광고 처리를 설명한다. |
| S09 | 접근성 | 키보드만으로 검색·저장·복사·대화상자 종료 가능. 입력 이름·포커스·상태 알림·충분한 대비를 검증한다. 360px와 데스크톱에서 콘텐츠가 잘리지 않는다. |
| S10 | 검색 노출 | 색인 대상 상세·가이드에 고유 title/description/canonical이 있다. sitemap은 공개·정상 페이지만 포함한다. 검색 매개변수·개인 선곡표·빈/초안 페이지는 색인 범위를 제어한다. |
| S11 | 배포 | 정확한 소스 SHA와 데이터 스냅샷으로 재현한다. 미리보기 검증, 기존 주소 호환, 마지막 정상 버전 복구 방법을 기록한다. |

## 품질 목표

초기 HTML만으로 핵심 곡 정보와 가이드를 읽을 수 있게 한다. 변경 전후 동일 기기 조건에서 LCP·INP·CLS를 측정한다. 목표는 현장 75백분위 LCP ≤ 2.5초, INP ≤ 200ms, CLS ≤ 0.1이며 트래픽이 부족하면 실험실 측정과 현장 측정을 구분한다. 검색 지연과 초기 JS/데이터 크기는 원본 측정 후 예산을 확정한다.

사업 지표는 성공적인 검색·번호 확인·다시 이용하는 선곡표다. 사용자 원문 검색어를 광고/분석 이벤트로 기본 전송하지 않는다. 트래픽이나 글 개수를 AdSense 승인 보장 조건으로 사용하지 않는다.

## 출시 조건

스펙 기준 검증, 출처·콘텐츠 검토, 기존 주소와 저장 데이터 호환, 미리보기 빌드, 배포 복구가 모두 확인돼야 새 조직 배포로 전환한다. 접근 권한 부족은 작업 상태에 기록하고 영향 없는 작업은 계속한다.
