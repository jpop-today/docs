Google의 콘텐츠 가치 판단은 페이지 수·문단 길이만으로 대체할 수 없다. 이번에 읽은 자격·정책 문서에서는 보편적인 최소 글 수·방문자 수·사이트 운영 기간을 승인 보장 조건으로 확인하지 않았다. G9는 선호하는 특정 단어 수가 없다고 설명한다. 임의 목표 수치나 실제 심사와 무관한 대기 기간을 승인 규칙으로 만들지 않는다.

AI 사용 사실 하나로 통과·거절을 예측하지 않는다. 실제 근거와 고유 가치, 사람이 수행한 조사·선별·검토를 확인하고 작성 과정을 사실대로 설명한다. AI 지원을 감추기 위해 가짜 작성자·전문가 프로필·검토자를 만들지 않으며 검색 순위를 조작하려는 대량 페이지를 만들지 않는다(G1, G9).

## 신청 전후 실행 기록

신청 전에 준비 항목 각각에 실제 파일·검증 결과·운영 URL과 SHA를 연결한다. 관측 미리보기 통과·소유권 확인 성공·ads.txt 상태·광고 script 로딩·광고 게재·심사 승인에는 각기 다른 증거가 필요하다. 광고 없는 브라우저 회귀 검증을 실제 광고 게재 확인으로 쓰지 않는다.

```text
조사/실행일 KST / 담당자:
관련 공식 정책 URL / 요구·권장 구분:
관련 스펙·Issue·PR / 운영 소스 SHA·deployment:
콘텐츠·권리·개인정보·광고·크롤링 검증 결과:
미확인 또는 차단 항목 / 다음 조치:
계정의 실제 사이트 상태 / 소유권·ads.txt 확인 결과:
검토 요청 사실·일시 / 제출 당시 artifact:
Google 통지의 실제 요지·결과일 / 수정 후 증거:
```

개인정보·계정 화면 원본·토큰을 공개 PR에 첨부하지 않는다. 거절이면 Google이 보낸 사유와 제출 당시 artifact를 보존하고 해당 문제에 대한 실제 개선을 검증한다. 글을 더 올렸다는 이유만으로 재심사 준비를 완료로 표시하지 않는다. 승인 후에도 콘텐츠·광고 배치·동의·무효 트래픽과 정책 변경을 점검한다.
