# AdSense 준비·심사 기록 기준

ADS-001. 프로젝트 목표는 유용한 JPOP 노래방 검색·선곡 서비스를 운영하며 AdSense 심사에 대응하는 것이다. 승인 결정은 Google이 내리며 특정 글 수·기간·방문자 수·AI 사용 여부만으로 결과를 보장하지 않는다.

## 실제 계정 상태

원본에 광고 설정·publisher 식별자·ads.txt가 있다는 사실과 실제 계정의 심사/게재 상태는 별개다. 운영 HTTP/공개 artifact는 확인했지만 AdSense 계정·실제 심사 상태는 직접 확인되지 않았다. 원본 README에는 ‘가치가 별로 없는 콘텐츠’ 메시지에 대한 설명이 있으나 이 세션에서 원본 심사 화면/날짜/계정 소유권을 확인하지 못했다. 현재 승인 상태는 unknown으로 둔다.

## 제출 전 증거

| 영역 | 필요한 증거 |
| --- | --- |
| 사용자 가치 | 실제 번호 검색·비교·저장 동작, 고유한 곡/가이드 본문, 무의미한 반복 페이지 없음 |
| 정확성 | 확인된 번호·사업자 상태·자료 출처·확인일, 관리 목록의 분모와 수집 지연 설명 |
| 권리 | 원문 가사·이미지·외부 자료의 허용 범위 또는 발행 제외 검사 |
| 운영 신뢰 | 실제 운영자/문의 안내, 제보 정상 처리, 실제 수집에 맞는 개인정보 안내 |
| 크롤링 | 운영 HTTP 상태·정적 본문·canonical/sitemap·robots와 Search Console 실제 확인 |
| 광고 | 계정 소유권/ads.txt 일치, 광고와 번호 복사·저장 버튼 구분, 해당 지역 동의 요구 검토 |
| 기술 | 모바일/키보드/접근성, 오류·빈 페이지·비공개 원본 유출 검사, 복구 가능한 운영 릴리스 |

광고 없는 preview 검증과 실제 광고 포함 운영 검증을 구분한다. 테스트의 광고 script stub은 광고 게재 확인이 아니다. 승인 전후에도 콘텐츠·광고 배치·무효 트래픽을 계속 점검한다.

## 계정과 심사 절차

운영자 본인정보·결제/세금·법적 동의는 사용자가 정확히 입력한다. 에이전트는 기술 준비·상태 정리·개선·위임된 실행을 담당하되 결과를 임의 확정하지 않는다. 심사 제출 가능 상태가 되면 운영 URL, 배포 SHA, 준비 증거, 제출일, 실제 결과와 Google 통지를 기록한다. 거절시 메시지와 해당 당시 artifact를 보존하고 근거 있는 개선 후 다시 평가한다.

- [Google 게시자 정책](https://support.google.com/adsense/answer/10502938?hl=ko)
- [사람 중심 콘텐츠](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko)
- [사이트 연결·소유권 확인](https://support.google.com/adsense/answer/12169212?hl=ko)
- [Cloudflare 정적 배포](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)

2026-10-13 Google 세 공식 문서를 HTTP200으로 읽었다. 게시자 정책의 저작권·가치 부족/복제 콘텐츠·광고 방해·개인정보 항목, Search Central의 사용자 중심/고유 가치/AI 사용 설명, 사이트 연결의 소유권·준비 상태·CMP 안내를 검토했다. Cloudflare 정적 배포 문서도 후속 HTTP200 요청으로 읽었으며 build command/output 설정과 정적 artifact 배포 지침을 확인했다. 정책 문서를 읽은 사실이 이 사이트의 준수·심사 통과를 뜻하지 않으며 적용 지역·실제 광고/동의 설정을 추가 확인한다. 내부 작업 문서는 공개 제품 본문으로 발행하지 않는다.

## 새 앱의 광고 발행 기준

공식 게시자 정책은 게시자 콘텐츠가 없거나 가치가 부족한 화면, 부가 가치 없는 복제 콘텐츠, 사용자 동작을 방해하는 광고를 제한한다. 새 앱은 reviewed 정적 곡/가이드/가수 콘텐츠부터 광고 발행을 검토하고 검색·개인 목록·빈 결과·404·draft 화면의 광고는 기본 제외한다. 소유권 meta/ads.txt, 스크립트 삽입, 실제 광고 게재·자동 광고 제외 설정은 각각 검증한다. 원본의 모든 페이지 광고 script 설정을 정책 준수 증거로 사용하지 않는다.
