# 검색 화면 설계와 구현 대조

2026-10-13 KST · SEARCH-001, FAVORITES-001, PREVIEW-001 · [Issue#5](https://github.com/jpop-today/jpoptoday/issues/5).

채택 기준은 [전체 검색 화면 콘셉트](search-concept.png)다. 내부 제작 시 Image Gen을 사용했으며 공개 사이트에는 이 이미지를 포함하지 않는다. 화면 텍스트와 컨트롤은 HTML/CSS/브라우저 코드로 구현한다. 기본 흰 배경, 검정 제목, 절제된 진홍색 선택 상태, 열린 곡 목록을 사용한다. 가사·외부 앨범 이미지·장식용 사진은 사용하지 않는다.

## 디자인 계약

| 항목 | 계약 |
| --- | --- |
| 배경/본문/강조 | #ffffff / #20242c / #bc2343 |
| 부문자/구분선/표 헤더 | #626b7b / #e6e7eb / #f5f6f8 |
| 구성 | wordmark+메뉴 → 제목·설명 → 검색 → 번호 조건 → 곡 표 → 더 보기·관측 안내 → footer |
| 컨테이너 | desktop 좌우88px, 최대1264px; 좁은 desktop32px, mobile16px |
| 타입 | 로컬 Noto Sans CJK KR 또는 시스템 sans, desktop 제목56px·설명22px·곡20px·부제15px·번호17px; mobile 제목28px·본문15px·곡17px |
| 컨트롤 | 검색62px/mobile52px, 번호44px, 저장44px; 구분선으로 목록 연결 |
| 아이콘 | 검색·복사·저장만 24px viewBox, outline1.7, currentColor |
| 모바일 | 곡명/저장 첫 줄, 업체명/번호 둘째 줄; 메뉴를 유지하고 가로 넘침 없음 |
| 동작 | URL 검색·복합 조건·뒤로가기, 번호 복사/실패시 선택 텍스트, 즐겨찾기 toggle·손상 원본 보존 |

첫 화면 허용 문구: jpop.today / 노래 찾기 / 즐겨찾기 / 이용 가이드 / 오늘 부를 JPOP를 찾아보세요. / 곡명, 가수, 노래방 번호로 검색하고 나만의 선곡 목록을 만드세요. / 곡명 · 가수 · TJ / 금영 번호 / 검색 / 전체 / TJ 번호 있음 / 금영 번호 있음 / 관측 번호 · 재확인 필요 / 노래 목록 / 곡·가수·TJ·금영·저장 / 더 보기 / 번호는 기존 목록의 관측값입니다. 방문 전 제공사에서 다시 확인해 주세요. / 서비스 소개 / 문의 / 개인정보처리방침.

콘셉트의 예시 번호는 실제 데이터 근거가 아니다. 실제 UI는 staging 관측값으로 교체한다. 현재 검색3313와 보관4를 구분하므로 콘셉트3317 전체 표시를 검색3313으로 교정한다. 내부 제작 보고는 공개 화면에 넣지 않는다.

## 대조 기록

Browser plugin이 세션에 없으므로 시스템 Chromium+Playwright fallback을 사용했다. 콘셉트 native1436×1096와 [desktop1440×1100 캡처](desktop.png), [mobile360×800 검색 상태](mobile.png)를 view_image로 직접 대조했다. 기능 테스트와 시각 검증을 별도로 수행했다.

| 비교점 | 콘셉트 / 실제 | 처리 |
| --- | --- | --- |
| 문구·순서 | 헤더/제목/검색/조건/5행/더보기/안내/footer | 허용 문구 유지, 위쪽 배지·추가 마케팅 문구 없음 |
| 데이터 | 콘셉트 예시번호·3317 vs 실제 관측번호·현재3313 | 의도한 사실 교정; 확인일·번호를 이미지에서 가져오지 않음 |
| 컨테이너·열 | 좌우88px/넓은 제목열/작은 번호 컨트롤 | 유지, 번호열20%·20%/저장12%로 위치 보정 |
| 제목·본문 | 굵은 큰 제목·회색 지원문구 | 첫 렌더의 작은 제목을56px/Noto fallback으로 보정 |
| 색·표현 | 흰 배경/진홍 선택/연회색 header/outline 복사·별 | 유지; 권리불명 이미지·사진 추가 없음 |
| 여백·footer | compact 전체 화면 | 검색·조건·footer 여백을 보정해 viewport 안 전체 화면 유지 |
| 모바일 | 좁은 화면의 검색·번호·저장 | 360px 가로넘침0, 제목 keep-all/balance로 끝 한 글자 줄바꿈 수정 |

위쪽 문구 대조에서 의도한 편차는 실제 관측 데이터·한글 가수 표기와 현재3313 개수뿐이다. 콘셉트와 구현의 큰 구도·타입·색·목록·컨트롤을 대조해 수정했으며 material mismatch는 남기지 않았다. 플랫폼별 로컬 시스템 폰트의 자형 차이는 생길 수 있다. 가이드·상세는 같은 디자인 토큰과 제품 스펙을 따른다.
