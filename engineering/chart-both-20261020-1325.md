## 사용자 흐름과 구현

검증할 흐름: `/chart/` → ‘TJ·금영 모두 확인된 곡’ 목록 열기 → 양쪽 번호·원제·가수 확인 → 보관된 원래 TJ 차트 행 → 기존 곡 상세의 공식 근거 확인.

- 네 번째 집계는 기존 strict `confirmedNumbers`에 두 업체가 모두 있는 동일 ID의 교집합이다. 원래 TJ/KY 집계·합집합·100개 순위/ID/`chart-<id>` 앵커·상세 URL은 유지했다.
- 두 업체 목록은 기본 접힌 native `details/summary`다. 기존 업체별 두 목록은 숨기지 않았다. 별도 script·저장 키·번호 복사 코드는 추가하지 않았다.
- 차트의 원제·가수·원래 순위와 안전한 두 업체 번호 문자열을 그대로 표시한다. 새 순위·공식 미수록·기기 수록·권리·Google 승인 상태를 만들지 않았다.
- 항상 보이는 안내는 동일 곡의 양쪽 근거라는 조건, JavaScript 없는 열기, 원래 TJ 순위와 금영 인기순위의 차이, 오래된 스냅샷, 0곡≠미수록을 설명한다.
- summary는 최소72px이고 기존 링크는 최소66px이다. 집계는 데스크톱4칸/700px 이하2칸이며 mint 패널을 사용했다. 기존 blue `#4f7cff`→pink `#ff7aa8` 장식과 공용 pink/mint/blue 배경은 보존했다.

## 검증 환경과 현재 경계

root가 준비한 단일 서버 `http://127.0.0.1:4323`에서 2026-10-20 05:21:46~05:21:56 UTC(14:21 KST)에 최종 실제 검증했다. Node `v24.19.0`, 저장소의 기존 Playwright와 `/usr/bin/chromium`을 사용했다. 임시 QA 스크립트와 결과는 `/tmp/jpop47-app-*`로 분리했고 별도 서버·패키지 설치·공유 build·Git 쓰기는 수행하지 않았다. 문서와 PNG의 커밋은 root가 수행한다.
