# 2026-10-13 운영 기준선 관찰

방법: GitHub API 메타데이터/contents와 공개 웹 텍스트 읽기. 소스·실제 브라우저·콘솔·HTTP 헤더·광고 요청 검사는 미실행. 관찰과 추정을 구분한다.

## 확인된 사실

- jpop-today/.github, docs, jpoptoday는 비공개 조직 저장소다. 최초 contents 조회는 empty repository였다. 사용자 연결에서 관리·쓰기 권한이 있었다.
- 운영 홈에는 한글 검색, 업체별 번호, 추천, TJ 차트, 가이드, 즐겨찾기와 소개·문의·개인정보 링크가 있다.
- 사이트 소개는 관리 목록 3,299곡과 초기 외부 자료를 설명한다. 이는 공개 안내의 값이며 원본 데이터로 검증한 수가 아니다.
- 차트에 마지막 수집 시각과 갱신 지연 안내가 있다. 실제 실패 원인과 스케줄 실행은 미확인.
- /song?id=jpop-playlist-official髭男dism-pretender-89fe1cbab6의 공개 텍스트는 곡 내용 없이 JavaScript 필요 안내를 표시한다. 동적 렌더링 후 기능은 확인하지 않았다.
- 안내 페이지는 브라우저 저장, Cloudflare, 외부 이미지, 문의, AdSense 가능성을 설명한다. 실제 스크립트/쿠키/CMP와의 일치는 미확인.
- sitemap.xml과 robots.txt는 이 웹 도구로 읽지 못했다. 서버에서 없다는 뜻이 아니다.
- 개인 원본 저장소 todayjpop은 연결 API와 공개 웹 모두 404다. 접근 권한과 환경 복구가 필요하다.

## 우선순위

P0: 원본·배포 접근, 기준선 확보, 출처/권리와 기존 ID·저장 데이터 조사.
P1: 상세 정적 HTML, 데이터 계약, 차트 실패 처리, 검색·저장 회귀 검증.
P2: UI와 편집 콘텐츠 개선, 광고/CMP·개인정보 실제 동작 대조, 신청 준비.
