# ADR 001: 정적 웹을 기본으로 하고 호환성을 지키며 이관한다

날짜: 2026-10-13. 상태: 제안. 확정 조건: 원본 todayjpop 소스·배포·성능 조사.

## 배경

운영 사이트는 정적으로 Cloudflare에서 제공된다. 검색·곡 정보·가이드는 일반 사용자별 서버 상태가 필요하지 않다. 공개 텍스트 조사에서 /song?id=... 상세는 실제 곡 정보 없이 JavaScript 안내가 보였다. HTML에서 직접 곡 정보를 읽을 수 있는 상세 라우트가 필요하다. 조직의 세 저장소는 처음 조사 시 비어 있었다.

## 제안

정적 HTML 생성과 프레임워크 독립 데이터 계약을 채택한다. 신규 정적 프레임워크가 필요하면 Astro + TypeScript를 우선 평가한다. 사이트 런타임 데이터베이스를 기본 도입하지 않는다. 실제 설치 버전은 구현 시 공식 문서와 호환성을 확인해 lockfile로 고정한다.

첫 이관은 기존 소스와 ID/URL/저장 데이터를 보존한 기준선 확보다. 그 뒤 검색·상세·편집 콘텐츠를 독립적으로 개선한다. 전면 교체가 더 낫다는 근거가 생기면 같은 호환성 검증을 수행한다.

## 대안과 판단

| 대안 | 장점 | 부담 |
| --- | --- | --- |
| 기존 정적 구조 유지 | 이관 위험과 변경 범위가 작음 | 현재 상세 HTML·모듈 경계의 한계 확인 필요 |
| Astro 정적 빌드 | 콘텐츠와 상세를 정적 생성, 선택적 JS | 기존 기능·저장 데이터 이관 필요 |
| 서버 중심 앱 | 개인화·실시간 변경에 유리 | 현재 요구보다 운영·권한·장애 범위 확대 |

## 결과

AdSense 준비를 위해 번호만 담긴 페이지를 대량 생성하지 않는다. 원본 소스 없는 상태에서 새 앱을 운영에 덮어쓰지 않는다. 제안 확정 시 원본과 후보의 빌드·번들·상세 HTML·호환성 결과를 이 ADR에 추가한다.
