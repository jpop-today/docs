# 곡 데이터 계약 v1

기계 검증 기준은 소스 저장소 contracts/catalog.mjs에 둔다. 데이터 구조 변경 시 해당 코드·테스트·이 문서를 함께 갱신한다. 초기 계약은 원본 이관 어댑터의 목표이며 원본 데이터가 이미 이 형식이라고 가정하지 않는다.

## 엔터티

| 필드 | 의미 |
| --- | --- |
| schemaVersion | 1. 구조 변경과 마이그레이션을 추적 |
| artists | 중복 없는 안정 ID, 원어 이름, 한글 이름, 별칭 |
| songs | 안정 ID, 원제, 한글 표시, 별칭, artistIds, version, karaoke |
| karaoke.tj / karaoke.ky | 업체별 status, number, sourceUrl, checkedAt |

번호 status는 registered(확인된 번호), unknown(자료 없음), unlisted(미수록이 확인됨)로 구분한다. registered 번호는 문자열이며 숫자로 변환해 앞자리 0을 제거하지 않는다. unknown에는 번호를 넣지 않는다. unlisted에는 확인 출처·날짜가 필요하다. checkedAt은 YYYY-MM-DD이며 실제 존재하는 날짜만 허용한다.

검증기는 중복 ID, 존재하지 않는 가수 참조, 번호 형식, 상태와 번호의 모순, 잘못된 출처 URL/날짜를 거부한다. 같은 업체 번호가 서로 다른 곡 레코드에서 사용되면 병합 후보 또는 버전 매핑으로 검토해야 하므로 자동 통과시키지 않는다.

## 출처와 권리

번호·태그·차트·사진·영상·글을 같은 출처로 묶지 않는다. 레거시 자료는 출처 불명 상태를 별도 이관 보고서로 남긴다. 출처를 모르는 번호에 임의 공식 URL이나 확인일을 붙여 검증을 통과시키지 않는다. 기존 사이트가 소개한 J-POP PLAYLIST 자료의 사용 범위·이용 허락은 아직 확인되지 않았다.

출처가 공개돼 있다는 사실을 이용 허락으로 간주하지 않는다. 가사 전문·번역·발음·커버 이미지는 재배포 근거가 확인된 경우에만 제공한다. YouTube는 공식 채널 링크와 적절한 임베드 중심으로 평가하고 원본 음원을 다운로드·재배포하지 않는다. 외부 영상만 붙인 상세를 고유 콘텐츠로 평가하지 않는다.

## 차트 스냅샷

provider, periodStart, periodEnd, fetchedAt(UTC ISO 시각), sourceUrl, entries(rank, providerNumber, songId 또는 unmatched 원본 표기)를 보관한다. 수집 성공 시각과 집계 기간을 구분한다. 타임존 표시는 Asia/Seoul을 사용한다. 파싱 오류·빈 응답·중복 순위·비정상 곡 수·큰 변경은 기존 파일 교체 전에 실패 또는 검토 대상으로 둔다.

기본 갱신 목표는 하루 한 번이다. 지연 안내 기준은 마지막 성공으로부터 36시간을 내부 후보로 두고 실제 운영 주기 확인 후 확정한다. 최신 데이터가 아닌데 최신으로 표시하지 않는다.
