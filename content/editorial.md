# 편집 콘텐츠 기준

콘텐츠는 한국어 사용자가 실제로 곡을 찾고 선곡하는 문제를 해결해야 한다. 작성자는 AI를 활용할 수 있으나 확인하지 않은 경험·난이도·음역·조회수·추천 이유를 사실처럼 쓰지 않는다.

## 상세 페이지

정확한 곡 정보, 업체별 번호 상태와 확인 근거, 같은 제목·버전의 구분, 관련 가이드·공식 확인 링크를 제공한다. 곡별 선곡 설명은 실제 검토 근거가 있을 때 추가한다. 제목·가수만 바꾼 공통 문단은 품질 요건을 채우지 못한다.

## 가이드와 데이터 분석

한 글은 한 구체적인 질문을 해결한다. 예시는 직접 검색·번호 대조로 확인한다. 데이터 분석에는 스냅샷 버전, 표본과 범위, 집계 규칙, 재현 가능한 계산, 해석의 한계를 적는다. 사이트의 등록곡 수를 업체 전체 곡 수로 설명하지 않는다.

작성/갱신일, 작성·검토 주체, 출처, 정정 경로를 갖춘다. 실제 업데이트 없이 날짜만 최신으로 바꾸지 않는다. 개인정보·문의 안내도 현재 구현과 대조한다.

## 초기 편집 과제

1. 기존 네 검색·번호·차트·선곡 가이드를 실제 UI와 대조한다.
2. TJ·금영 비교 분석을 실제 데이터 스냅샷으로 재현한다.
3. 자주 검색되는 곡의 버전·표기 오류부터 정정한다.
4. 근거를 확보한 선곡 가이드를 추가한다. 목표 편수나 글 길이는 Google 승인 조건으로 설명하지 않는다.

외부 글을 요약해 양만 늘리거나 검색 순위를 위해 유사 페이지를 대량 생성하지 않는다. 콘텐츠 공개 판단은 실제 유용성·정확성·권리 근거를 함께 확인한다.
