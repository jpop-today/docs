# 편집·자료 이용 기준

CONTENT-001, DATA-001, ADS-001. 목적은 사용자가 JPOP 곡을 찾고 TJ/KY를 비교하며 선곡할 때 필요한 설명을 제공하는 것이다.

## 콘텐츠 단위

곡 페이지는 한국어/원제·가수·버전·사업자별 번호 상태·확인 근거·정정 경로를 제공한다. 가수 페이지는 관리 목록의 실제 비교와 검토된 설명을 담는다. 가이드는 한글/원제 검색법, 번호 사업자 차이, 차트 기간 읽기, 개인 선곡 목록 같은 구체적 문제를 해결한다. 데이터가 비어 있거나 고유 설명이 없으면 페이지를 자동 발행하지 않는다.

초기 편집 backlog: 기존 네 가이드 사실 검토, 관측 번호와 공식 확인 번호의 차이 설명, TSV 인용부호·버전 차이의 검색 영향 조사, 실제 관리 목록의 사업자별 범위와 제보 절차. 제목을 바꾼 동일 본문이나 근거 없는 추천·난이도·음역·가사 해석을 대량 생성하지 않는다.

## 발행 기록

각 문서에 slug, title, 목적/대상, 작성자, 작성일, 실제 검토일, 참고 출처, 자료별 권리 근거, 검토 상태(draft/reviewed/published), 정정 이력을 둔다. 수정 시각을 자료 확인일로 대체하지 않는다. 개인 이름·이메일은 운영자가 공개할 정보를 확정한 경우만 사용한다.

AI는 구조화·표현·초안·코드 검증을 도울 수 있지만 인용·사실·이용 권한의 근거를 만들어내지 않는다. 곡 수와 coverage는 고정 snapshot에서 계산하고 분모가 전체 JPOP 시장이 아닌 관리 목록임을 명시한다.

## 권리와 출처

번호·메타데이터의 출처 URL, 관측/확인 시각, 수집 방식, 재배포 범위를 기록한다. TJ 공식 차트 출처와 전체 등록 목록의 출처를 혼동하지 않는다. 가사 전문·앨범 이미지·YouTube 캡처를 기본 콘텐츠로 가져오지 않는다. 자료 이용 허락·라이선스가 확인되면 범위·증거·제외 요청 처리 경로를 남긴다. 공식 YouTube 링크/임베드도 약관·프라이버시·대체 텍스트를 검토하며 썸네일을 임의 복제하지 않는다.

## 검토와 정정

맞춤법/원제/가수/버전/번호/출처를 대조하고, 사용자에게 도움이 되는 고유 내용인지 확인한다. 오류 제보는 현행 연락 경로의 정상 작동과 개인정보 취급을 확인한 뒤 연결한다. 정정은 근거·변경 항목·영향 ID/URL·배포 SHA를 기록한다. 조회수를 만들기 위한 재방문/광고 클릭 유도는 하지 않는다.
